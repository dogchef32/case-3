# Кейс № 3 — персональное приветствие на Django

Приложение принимает имя через форму, сохраняет его в базе SQLite и выводит персональное приветствие. Реализованы обработка пустого ввода, CSRF-защита и HTML-экранирование.

## Запуск на Windows

1. Установите Python 3.10+.
2. Откройте папку проекта и запустите `Запустить.bat`.
3. При первом запуске установятся зависимости и создастся база данных (требуется интернет).
4. Откройте в браузере `http://127.0.0.1:8000/`.
5. Для остановки сервера нажмите Ctrl+C в окне консоли.

## Тесты

`python manage.py test`

Примечание: `db.sqlite3` создаётся автоматически. Запуск через двойной щелчок по `index.html` невозможен, потому что Django — серверное приложение.
